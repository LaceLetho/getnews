        "⚠️ 删除冲突\n\n"
        f"数据源 ID {datasource_id} 当前不能删除，因为已关联到 {exc.topic_count} 个主题。\n"

    )
    self._log_expected_command_outcome(
        command="/datasource_delete",
        user_id=user_id,
        username=username,
        chat_type=chat_type,
        chat_id=chat_id,
        outcome="datasource delete blocked by topic association",
    )
    await update.message.reply_text(response)
    self._log_command_execution(
        "/datasource_delete",

    return

## Behavior

1. **Associated datasource** (`/datasource_delete <id>`):
   - Reply: "⚠️ 删除冲突\n\n数据源 ID {id} 当前不能删除，因为已关联到 {count} 个主题。\n请先使用 /topic_sources_remove 解除关联。"

2. **Unassociated datasource**:
   - Reply: "✅ 数据源删除成功\n\n已删除数据源 ID: {id}"

3. **Non-existent datasource**:
   - Reply: "❌ 未找到数据源\n\n未找到 ID 为 {id} 的数据源。"
